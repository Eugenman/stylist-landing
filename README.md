# stylist-landing

Pet project: одностраничный сайт-визитка персонального стилиста.

Стек: React 19, Vite, TypeScript, styled-components, i18next.

## Требования

- Node.js 20+

## Установка

```bash
npm install
```

## Разработка

```bash
npm run dev
```

Откроется локальный сервер (обычно http://localhost:5173).

## Сборка

```bash
npm run build
```

Результат — папка `dist/`.

## Превью production-сборки

```bash
npm run preview
```

## Форматирование и линт

```bash
npm run lint          # ESLint + Prettier check
npm run eslint:lint   # только ESLint
npm run format        # записать Prettier
npm run format:check  # только проверка Prettier
```
